# Body Stroke

カメラで体の動きを記録して、そのストロークで絵を描く実験ツールです。
ブラウザだけで動きます（PC・スマホ対応）。

**公開ページ：https://murakamimikiart-design.github.io/body-stroke/**

## 使い方

1. ページを開いて、カメラの使用を許可します。
2. 「● 記録スタート」を押すと、3秒のカウントダウンのあと5秒間記録します。
3. 記録した動きが、右（スマホでは下）の画面に線で描かれます。
4. 「▶ 再生」で描き直し、「PNG保存」で画像を保存できます。
5. 「🎬 工程を動画で保存」で、左に映像（骨組みの線つき）、右に描かれていくストロークを並べた動画を保存できます。保存する時点の色やスライダーの設定が使われます。

### 動画から読み込む

「🎞 動画から読み込む」で動画ファイルを選ぶと、解析する範囲（開始・終了）を選ぶ画面が出ます。
「▶ この範囲を解析」を押すと、その範囲を1コマずつ解析してストロークを描きます（PC は1秒30コマ、スマホは1秒15コマ）。
動画では手・顔・体を別々に探す MediaPipe Tasks を使うので、体が映っていない手や顔のアップでも検出できます。
「● 記録スタート」を押すとカメラに戻ります（動画から描いた絵は消えます）。

## 描かれるもの

| 部位 | 描き方 |
|---|---|
| 指先（親指〜小指） | 指先の軌跡を線で描く（筆のような入り・抜きと太さの強弱） |
| 目 | 黒目の位置を、決めた回数だけ点で描く（回数・点の大きさはスライダーで調整） |
| 口 | 唇の形（外側・内側の輪郭）を、決めた回数だけ重ねる（初期は4回） |
| 肩・上腕・前腕 | 骨組みの線を毎フレーム薄く重ねる |
| 手のひら・指の骨組み | 骨組みの線を毎フレーム薄く重ねる |
| 全身（体幹・太もも・すね・足） | 骨組みの線を毎フレーム薄く重ねる。つま先は軌跡の線 |
| 物（素材） | 輪郭を、決めた回数だけ重ねる（線だけ／塗りつぶし／両方） |

- ゆっくり動くと太く濃く、すばやく動くと細く薄くなります。
- 色の丸をクリック（タップ）すると、各部位と背景の色を変えられます。
- 背景は単色のほか、「背景」から「背景2」へのグラデーション（上から下へ／左から右へ／斜め／中心から外へ）にできます。
- 「人差し指の太さ」で人差し指だけ太くしたり、「指先の線」で人差し指だけを描いたりできます。
- 「奥行きの効き」を上げると、手をカメラに近づけたときに線が太く濃くなります（筆圧のような表現）。
- 「手の形の確認」で、ありえない形に見間違えた手を捨てます。1つの手を左右両方として二重に見つけたときも、1つにまとめます。
- 調整ツールは「全体（背景・描き方）」「人（体・手）」「物体（素材・動物）」の3つのゾーンに分かれています。見出しを押すと開け閉めできます。
- 線の太さ、太さの変化、濃淡（人と物体で別々）、体の骨組みの濃さは、スライダーで調整できます。記録したあとに動かすと、その場で描き直されます。

## 物（素材）に触れる動きを記録する（動画のみ）

1. 「輪郭を取るもの」で、どちらかを選びます。
   - **色で選ぶ**：粘土など、手に持って形を変える素材向け。タップした所の色を覚えて追いかけます。
   - **タップして選ぶ**：種類を問わず、タップしたものの形を切り出して追いかけます。
2. 「輪郭の数」を1以上にして、動画を読み込みます。範囲を選ぶ画面で、映像の中の素材をタップします。
3. 「触れているときの線」で、指先が素材に触れている間だけ線を強くしたり、触れている所だけを残したりできます。
4. 「描き方」を「連続写真」にすると、映像から手と素材だけを切り抜いて、半透明で重ねた写真になります。

- **人の確認**：顔と体の検出が、犬などを人と見間違えないよう、人の範囲にある顔・体だけを使います。
- **撮り方のコツ**：スマホを固定して、手と素材の両方が入るように横か斜め上から、明るく影の少ない場所で撮ると、うまく追いかけられます。

## 習字は Air Shuji へ

人差し指を筆にして空中に字を書く習字は、[Air Shuji](https://murakamimikiart-design.github.io/air-shuji/) に分けました（同じコードで、習字のモードに固定したものです）。

## 仕組み

- カメラでは [MediaPipe Holistic](https://github.com/google/mediapipe)、動画では MediaPipe Tasks（手・顔・体を別々に検出）を使っています。
- 物の形と人の範囲は DeepLab v3（画像セグメンテーション）と Interactive Segmenter、または色で取っています。
- 映像はブラウザの中だけで処理されます。外部には送信しません。

## ローカルで動かす

Mac では `起動.command` をダブルクリックすると、`http://localhost:8010/` で開きます。
