# Body Stroke

カメラで体の動きを記録して、そのストロークで絵を描く実験ツールです。
ブラウザだけで動きます（PC・スマホ対応）。

## 使い方

1. ページを開いて、カメラの使用を許可します。
2. 「● 記録スタート」を押すと、3秒のカウントダウンのあと5秒間記録します。
3. 記録した動きが、右（スマホでは下）の画面に線で描かれます。
4. 「▶ 再生」で描き直し、「PNG保存」で画像を保存できます。
5. 「🎬 工程を動画で保存」で、左に映像（骨組みの線つき）、右に描かれていくストロークを並べた動画を保存できます。保存する時点の色やスライダーの設定が使われます。

### 動画から読み込む

「🎞 動画から読み込む」で動画ファイルを選ぶと、解析する範囲（開始・終了）を選ぶ画面が出ます。
「▶ この範囲を解析」を押すと、その範囲を1コマずつ解析してストロークを描きます（PC は1秒30コマ、スマホは1秒15コマ）。
動画では手・顔・体を別々に探す MediaPipe Tasks を使うので、体が映っていない手や顔のアップでも検出できます。
「● 記録スタート」を押すとカメラに戻ります（動画から描いた絵は消えます）。

## 描かれるもの

| 部位 | 描き方 |
|---|---|
| 指先（親指〜小指） | 指先の軌跡を線で描く（筆のような入り・抜きと太さの強弱） |
| 目 | 黒目の位置を、決めた回数だけ点で描く（回数・点の大きさはスライダーで調整） |
| 口 | 唇の形（外側・内側の輪郭）を、決めた回数だけ重ねる（初期は4回） |
| 肩・上腕・前腕 | 骨組みの線を毎フレーム薄く重ねる |
| 手のひら・指の骨組み | 骨組みの線を毎フレーム薄く重ねる |

- ゆっくり動くと太く濃く、すばやく動くと細く薄くなります。
- 色の丸をクリック（タップ）すると、各部位と背景の色を変えられます。
- 線の太さ、太さの変化、濃淡、肩・腕の濃さは、スライダーで調整できます。記録したあとに動かすと、その場で描き直されます。

## 仕組み

- 体・手・顔の検出には [MediaPipe Holistic](https://github.com/google/mediapipe) を使っています。
- 映像はブラウザの中だけで処理されます。外部には送信しません。

## ローカルで動かす

Mac では `起動.command` をダブルクリックすると、`http://localhost:8010/` で開きます。
